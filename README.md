# HvordanErVejret

## Overview

The Code Base for the Web Application: [HvordanErVejret.dk](https://hvordanervejret.dk/forside/).
This site is dedicated to the podcast with the same name *Hvordan Er Vejret*, a podcast that dives into the everyday
lives, experiences, and personal stories of its hosts and creators, ***Hans-Peder Andersen*** and ***Martin Fromberg Hansen***.

## Technologies

The application is powered by [Nuxt.js](https://nuxt.com/)
